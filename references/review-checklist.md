# 校审检查清单

> 本清单供各角色参考，详细职责请参阅各角色的 prompt 文件。

## 审查原则

**重点审查内容问题，不审查Word转MD产生的格式问题。**

---

## 一、general-checker 检查项

### 1.1 规范版本核实（⚠️ 必须执行）

**检查步骤**：
1. 使用 grep 提取所有引用的规范编号
2. 使用 MCP 工具查询最新版本
3. 对比文档引用版本与最新版本

**常见过期规范**（详见 `references/common-errors.json`）：
- GB50011 建筑抗震设计规范
- GB50016 建筑设计防火规范
- DL/T5352 高压配电装置设计规范
- DL/T5222 导体和电器选择设计技术规定

### 1.2 术语正确性

**常见术语错误**（详见 `references/common-errors.json`）：
- "水文地址" → "水文地质"
- "物证" → "校审"
- "站埴" → "站址"

### 1.3 数据一致性

必须检查的数据项：
- 主变容量：系统部分 vs 电气一次部分
- 出线数量：系统部分 vs 电气一次部分
- 无功补偿容量：系统部分 vs 电气一次部分
- 短路电流计算结果

### 1.4 站名统一性

**检查方法**：
1. 使用 grep 提取所有站名
2. 检查是否有多种写法
3. 记录不一致的站名

```bash
grep -oP "[^[:space:]]{2,}站" 文件.md | sort | uniq -c | sort -nr
```

### 1.5 表格编号

```bash
grep -oP "表\d+-\d+" 文件.md | sort | uniq -d
```

## 二、senior-engineer 检查项

### 2.1 系统专业
- 负荷预测方法合理性
- 接入系统方案合规性
- 无功补偿计算正确性
- 短路电流计算准确性

### 2.2 电气一次
- 主变参数（容量、阻抗、调压）
- 电气主接线描述
- 设备选型与遮断容量
- 导体校验

### 2.3 电气二次
- 保护配置完整性
- 自动化系统配置
- 通信方式
- 对侧站保护改造

### 2.4 土建
- 抗震设防标准
- 地基处理方案
- 建筑结构

### 2.5 概算
- 概算编制依据
- 工程量统计
- 定额套用

---

## 三、reviewer 检查项

### 3.1 问题位置格式修正（核心职责）

- 所有 location 字段必须使用章节编号格式
- 行号格式（如"第3035行"）必须修正为章节编号

### 3.2 输出格式审查

- 分类名称：系统/电气一次/电气二次/土建/水暖/概算/综合/其他
- 问题描述是否具体准确
- 修改建议是否可行

### 3.3 遗漏检查

- 检查是否有未被发现的明显问题
- 检查检查项是否覆盖完整

---

## 四、不记录的问题

**Word转MD格式问题**（不记录）：
- LaTeX公式残留
- 空格分隔的数字
- Word转换错误标记
- 测试数据

---

## 五、问题位置格式

❌ 错误：`第6407行`、`第3035行`
✅ 正确：`第3章第2.1节`、`第4章表4-1`
